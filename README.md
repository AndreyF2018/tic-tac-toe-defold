# Крестики-нолики на Defold с использованием LLM

## Описание проекта

В рамках тестового задания реализована игра "Крестики-нолики" на игровом движке Defold.

### Основные возможности:
- Игровое поле 3x3
- Игра против простого AI (случайные ходы)
- Система монет (награда за победу/ничью)
- Графический интерфейс с использованием ассетов, сгенерированных ИИ.
- Обработка пользовательского ввода (клики)
- Сохранение прогресса (монеты)

---

## Архитектура проекта

Проект состоит из двух основных компонентов:

- `game.script` — игровая логика
- `gui.gui_script` — пользовательский интерфейс

Взаимодействие между ними происходит через систему сообщений Defold (`msg.post`).

## Используемые ИИ-агенты

В проекте использовались следующий ИИ-агенты:

- локальная LLM модель deepseek-r1:8b через платформу Ollama
- Веб-версия LLM DeepSeek
- Веб-версий LLM ChatGPT

### Роль LLM:
- генерация базового кода
- помощь в написании функций
- исправление ошибок
- объяснение работы Defold API

## Примеры используемых промптов

### 1. Генерация начальной логики игры
```
Напиши игровой контроллер для крестиков-ноликов на Lua для Defold.Нужны функции:
инициализация доски 3×3, проверка победы по строкам/столбцам/диагоналям, обработка кликов по клеткам.
Используй msg.post для коммуникации с GUI.

```
---

### 2. Система монет и сохранений
```
Добавь в game.script систему награждений монетами: +10 за победу, +5 за ничью, 0 за поражение.
Монеты должны сохраняться между запусками через sys.save и sys.load.
```

---

### 3. Реализация AI
```
Добавь простой AI:
- игрок играет за "x", AI за "o"
- AI ходит случайно
- AI выбирает случайную свободную клетку
- AI делает ход после игрока
```

### 4. Добавление логики для кнопки "Reset"
```
Напиши логику для кнопки сброса.
По нажатию на неё должна происходить очистка игрового поля,
сбрасываться флаг окончания игры и обновляться интерфейс.
Монеты при этом не должны обнуляться
```
---

### 5. Отладка ошибки
```
Ошибка: sys.save ожидает table, а не string.
Как правильно сохранять данные?
```

### 6. Генерация ассетов
```
Создай изображение (png формата) поля для игры в крестики нолики.
Она должна быть пригодной для использования в качестве ассета в 2d игре.
```
```
В этом же стиле создай отдельно изображение для крестика.
На изображении не должно быть белого фона.
Оно должно аутентично выглядеть на игровой доске.
```

*Аналогичный промпт для изображения нолика*

## Workflow работы с ИИ

Использовался итеративный подход:

1. Формулировка задачи
2. Генерация кода через LLM
3. Интеграция в проект
4. Тестирование
5. Исправление ошибок через новые промпты

Каждый результат проверялся и дорабатывался вручную.

---

## Что было исправлено вручную

Несмотря на использование LLM, некоторые моменты были доработаны вручную:

- Расстановка GUI объектов на координатной сетке
- Вручную выявлена проблема с сообщениями на кириллице
- Изменение разрешения ассетов-изображений, сгенерированных ИИ на подходящее
- Исправлено свойство Visible для Box крестиков и ноликов (LLM ошибочно рекомендовал убрать галочку)
- Исправлена работа `sys.save` (ожидает table)
- Исправлено взаимодействие GUI и логики
- Добавлена защита от некорректных данных (`tonumber`, `tostring`)
- Исправлены ошибки обработки кликов
